# E-commerce Checkout

Aplicación e-commerce desarrollada como prueba técnica.

## Estructura

- `apps/backend`: API REST con Java y Spring Boot.
- `apps/frontend`: aplicación web con Angular.
- `database`: scripts de esquema, datos semilla y restauración.
- `docs`: documentación técnica y decisiones del proyecto.

La implementación se desarrollará de forma incremental mediante ramas de funcionalidad y commits descriptivos.
